# go-fund-operations

开放式基金交易与估值服务的 Go 项目基础模块。

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## 侧袋机制（sidepocket 包）

当基金持有不易变现资产时，通过侧袋划分将该部分资产对应的历史权益
从主基金中分离出来，避免后续申赎的投资者摊薄或搭便车。

### 主基金份额与侧袋权益的区别

- **主基金份额**：普通申购、赎回的对象。登记日之后申购的投资者只取得
  主基金份额；赎回只扣减主基金份额，可赎回数量仅按主基金份额计算。
- **侧袋权益**：方案确认时按登记日日终持仓冻结生成，独立于主基金份额。
  原投资者赎回主基金份额后侧袋权益继续保留；侧袋权益可以随账户转移，
  但不得与主基金份额混合计算可赎回数量。

### 业务流程

1. `CreatePlan` 创建方案，记录基金、目标资产、登记日、资产估值、
   划分比例（万分比）和方案版本。
2. `ConfirmPlan` 确认方案：冻结登记日投资者的主基金份额基数，按比例
   生成侧袋权益；采用最大余数法取整，所有投资者权益合计恒等于方案总量。
3. `TransferEntitlement` 在账户间转移侧袋权益，转移不改变权益总量。
4. `ConfirmRecovery` 登记目标资产的现金回收。
5. `DistributeRecovery` / `ScanAndDistribute` 按当前有效侧袋权益生成
   分配明细；每笔回收只分配一次，重复扫描幂等。
6. `DistributionsOf` 查询分配明细。

权益转移、回收确认与分配扫描在互斥锁下串行执行，每一份权益只归入
一名最终持有人，不会重复分配。
