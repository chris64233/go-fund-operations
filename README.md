# go-fund-operations

开放式基金交易与估值服务的 Go 项目基础模块。

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## corporateaction 包：基金份额拆分与合并

`corporateaction` 实现份额拆分（share split）与份额合并（share merge）
公司行动的完整生命周期：

```
DRAFT → CONFIRMED → EXECUTING → EXECUTED
  └────────┴── CANCELLED（仅执行前可取消）
```

### 行动定义与比例

- 行动保存基金、适用份额类型、登记日、生效日、转换比例与当前状态。
- 比例以正整数分数 `Ratio{Num, Den}` 表示（每份旧份额兑换 `Num/Den`
  份新份额），登记时按最大公约数归一化：`Num > Den` 为拆分，
  `Num < Den` 为合并，`1:1` 为等比例；比例必须为正，生效日不得早于登记日。
- 同一基金、同一份额类型在 `[登记日, 生效日]` 闭区间重叠期间不得存在
  另一个未取消行动（相邻日允许），防止同一批份额被重复转换；不同份额
  类型互不影响；取消后窗口释放。

### 登记日快照

- 确认（`ConfirmAction`）时按登记日日终冻结持有人份额快照
  （总份额与其中冻结份额）：申购、赎回、份额冻结的生效日早于或等于
  登记日才纳入；生效日晚于登记日的交易（即使在转换生效日之前）不纳入。
- 快照冻结后拒绝补登生效日早于或等于登记日的交易或冻结；之后的新
  交易正常受理但不改变快照，执行只按快照数量转换，不会被重复转换。
- 登记日（含）前冻结的份额按同一比例转换，转换后继续冻结。

### 转换与零碎份额

定点数：份额单位 0.01 份，零碎份额以 1e-6 份精度保留，金额单位分。

- 新份额 = 旧份额 × `Num/Den`，**向下取整到 0.01 份**；
- 无法整除被舍去的零碎份额记录在转换明细 `FractionalShares` 中，
  作为差额来源永久保留；
- 零碎份额按基金份额面值 **1.00 元/份**折算现金返还持有人
  （`CashInLieu`，四舍五入到分）；
- 旧份额不删除，以负数注销流水（`CONVERSION_RETIRE`）保留，
  新份额与零碎现金为正数流水（`CONVERSION_ISSUE`）。每条转换明细
  可追溯原持有人、转换前数量、零碎差额与所采用的行动版本（`Version`）。

### 幂等、并发与恢复

- 同一行动号重复登记：内容完全一致返回原行动（比例经 GCD 归一化后
  比较）；基金、份额类型、日期或比例不同返回 `ErrActionConflict`。
- 执行以行动号 + 全部关键参数为幂等键：重复执行返回原执行结果，
  参数不一致返回 `ErrExecutionConflict`；重复扫描不再次增加或减少份额。
- 状态迁移由服务锁串行化，转换逐条以幂等键入账；执行、取消与持仓
  变动并发时每名持有人只形成一份最终转换结果，执行开始后取消被拒绝。
- 执行中断后行动停留在 `EXECUTING`，再次执行只补齐未完成明细。
- 每次状态变化持久化到 `StatusHistory`；取消后快照仍可查询。

### 主要接口

| 方法 | 说明 |
| --- | --- |
| `PostTrade` | 登记申购/赎回交易（带生效日，用于快照归属） |
| `PostFreeze` | 登记份额冻结/解冻（带生效日，不改变总份额） |
| `Register` | 登记公司行动（基金、份额类型、登记日、生效日、比例） |
| `ConfirmAction` | 确认行动并冻结登记日快照 |
| `Execute` | 执行/恢复执行，幂等返回 `ExecutionResult` |
| `CancelAction` | 执行前取消行动（幂等） |
| `GetAction` / `Snapshot` / `Conversions` / `HolderConversion` / `Execution` / `StatusHistory` | 行动、快照、转换结果与状态历史查询 |
| `Holdings` / `CashBalance` | 持有人总份额/冻结份额与零碎现金查询 |

### 测试覆盖

`corporateaction/` 下的测试覆盖：比例边界（非正、1:1、GCD 归一化）、
登记冲突与生效期间重叠、零碎份额向下取整与现金替代、登记日交易与
冻结归属、冻结份额同比例转换、重复执行幂等与参数冲突、生效日后
新交易不重复转换、中断恢复、执行/取消/持仓并发下结果唯一。
