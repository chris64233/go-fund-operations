# go-fund-operations

开放式基金交易与估值服务的 Go 项目基础模块。

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## capitalcall：出资承诺与缴款通知

`capitalcall` 包实现私募基金分期调用（capital call）的核心流程：

- **承诺登记**：`RegisterCommitment` 记录币种、承诺总额、已调用金额与有效状态；`DeactivateCommitment` 停用后不再参与分配。
- **通知生成**：`CreateNotice` 按各投资者未调用承诺比例分配目标总额，生成时冻结全部有效承诺的剩余额度；额度不足则整份失败，不产生任何占用。
- **比例舍入**：金额以最小货币单位（分）计算，向下取整后按小数余数从大到小补齐，保证分配之和等于目标总额，且单项不超过该投资者剩余额度。
- **缴款确认**：`ConfirmPayment` 支持分次缴款，累计实缴不得超过应缴；以银行流水号为幂等键，重复流水返回首次结果，不重复增加实缴。
- **取消**：`CancelNotice` 释放未缴部分的承诺占用，已缴部分保持已调用；与缴款、其他通知并发时由单把互斥锁保证承诺占用、已调用金额与现金记录一致。
- **查询**：`Allocations` 查看通知分配，`OverdueNotices` 列出逾期通知，`Position` 区分未调用、已通知未缴与已实缴金额。

运行测试（含竞态检测）：

    go test -race ./capitalcall/
