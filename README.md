# go-fund-operations

开放式基金交易与估值服务的 Go 项目基础模块。

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## capitalcall：出资承诺与缴款通知

`capitalcall` 包实现私募基金按项目需要分期调用投资者承诺额度的功能。
所有金额使用整数最小单位（如分），保证舍入精确。

### 核心概念

- **承诺（Commitment）**：记录币种、承诺总额、已调用金额、已实缴金额和有效状态。
  失效的承诺不参与新的通知，但保留历史数据。
- **缴款通知（Notice）**：包含用途、币种、目标总额、到期日和投资者分配。
  生成时按各投资者**未调用承诺比例**分配目标金额，采用最大余数法舍入，
  保证所有分配之和恰好等于目标总额，且任何分配不超过该承诺的剩余额度。
  生成通知会**冻结**全部分配额度：并发通知不能重复占用同一份未缴承诺；
  未调用总额不足时整份通知失败，不产生任何预留。
- **缴款（Payment）**：支持分次确认，累计实缴不得超过个人应缴金额。
  每笔缴款记录银行流水号；同一流水号重复确认是幂等的，不会重复增加实缴金额。
- **取消**：取消通知时，未缴部分的占用释放回未调用额度，已实缴部分保持不变。

### 并发与一致性

所有变更操作由同一互斥锁串行化，并先校验后落账：承诺占用、已调用金额
和现金记录要么一起更新，要么都不更新，失败不会只更新其中一项。

### API 概览

- `RegisterCommitment` / `SetCommitmentActive`：承诺登记与启停
- `GenerateNotice`：生成通知并冻结额度
- `GetNotice` / `GetAllocation`：通知与投资者分配查询
- `ConfirmPayment`：缴款确认（按银行流水幂等）
- `CancelNotice`：取消通知并释放未缴占用
- `Position`：投资者头寸查询，区分未调用、已通知未缴、已实缴
- `OverdueNotices`：查询已过期且未缴清的通知
