# go-fund-operations

开放式基金交易与估值服务的 Go 项目基础模块。

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## 侧袋机制（sidepocket 包）

当基金持有不易变现资产时，通过侧袋划分将该部分资产对应的历史权益
冻结为独立的侧袋权益，与主基金份额隔离。

### 主基金份额与侧袋权益的区别

- 主基金份额：日常申购、赎回的标的，可赎回数量只按主基金份额计算；
  登记日之后申购的新投资者只取得主基金份额。
- 侧袋权益：方案确认时按登记日（含）前生效的主份额和冻结比例生成，
  代表对目标不易变现资产的历史权益。它不参与主基金申赎计算，
  投资者赎回全部主份额后侧袋权益仍保留；侧袋权益可以在投资者
  账户之间转移，但不得与主基金份额混合计算可赎回数量。

### 业务流程

1. `CreatePlan` 创建方案，记录基金、目标资产、登记日、资产估值
   （侧袋权益总量）、冻结比例与方案版本。
2. `ConfirmPlan` 确认方案：以登记日（含）前生效的主份额为基数按比例
   生成侧袋权益，采用最大余数法保证所有投资者权益合计等于方案总量。
3. `TransferEntitlement` 在账户间转移侧袋权益；转移在锁内原子完成，
   并发转移下总量守恒、不会出现负权益。
4. `RecoverCash` 登记目标资产的现金回收；`ScanDistributions` 按当前
   有效侧袋权益生成分配明细，扫描幂等——并发或重复扫描只生成一份
   明细，每一份权益只归入一名最终持有人，不会重复分配。
5. `DistributionDetails` 查询某次回收的分配明细。
